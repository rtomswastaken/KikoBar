# Security Policy

## Supported Versions

Kikobar is currently under active beta development. Security updates are applied directly to the primary development branch.

| Version | Supported          |
| ------- | ------------------ |
| Beta    | :white_check_mark: |
| < Beta  | :x:                |

## Reporting a Vulnerability

Security issues should be reported responsibly. If you discover a security vulnerability or sandbox issue (such as unauthorized file read/write, bookmark leak, or pasteboard data exposure), please do not open a public issue.

Instead, please report it privately:

- Contact the maintainer directly via GitHub Security Advisories or email `richardsenthomas555@gmail.com`.
- Include detailed reproduction steps, the nature of the vulnerability, and sample payloads if applicable.
- You should receive an acknowledgment within 48 hours.

Once verified, fixes will be committed directly to `main` and credited in the subsequent release notes unless anonymity is requested.
